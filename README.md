# NorthLink AI 

An AI-powered, accessible support ticket system built with **Next.js 15**, **Azure**, and **OpenAI**. Designed with a focus on **WCAG 2.1** compliance and modern DevOps practices.

## Tech Stack
- **Frontend:** Next.js (App Router), Tailwind CSS, TypeScript.
- **Backend:** Next.js API Routes, Mongoose.
- **Database:** Azure Cosmos DB (MongoDB API).
- **AI:** OpenAI API for automated ticket summarization & priority.
- **Testing:** Playwright (E2E) & axe-playwright (Accessibility).
- **Infrastructure:** Docker, GitHub Actions (CI/CD), Azure.

## Getting Started
First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open http://localhost:3000 to see the result.
